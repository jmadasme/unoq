# rec/ — video explicativo

Este directorio contiene el video asciinema de **UNO Q: dos cerebros, un protocolo** y el reproductor
que se usa en la página del proyecto.

- `unoq.cast`: grabación original (asciicast v2).
- `unoq.cast.js`: los eventos embebidos para el reproductor inline.
- `player.js` / `player.css`: reproductor reutilizable.

Duración: 3:02. Los fragmentos de código son reales y
corresponden a los archivos y líneas indicados en el video.
